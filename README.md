# ลงเวลาทำงาน — วิธีขึ้น Vercel (มือใหม่ทำตามได้เลย)

ทำผ่านเบราว์เซอร์ล้วนๆ ไม่ต้องลงโปรแกรมอะไรเพิ่ม ใช้เวลารวมประมาณ 15-20 นาที

สิ่งที่ต้องมีก่อนเริ่ม: ไฟล์ `timeclock-app.zip` ที่ดาวน์โหลดไว้จากแชท

---

## ขั้นที่ 0 — แตกไฟล์ zip

หาไฟล์ `timeclock-app.zip` ที่ดาวน์โหลดมา แล้วดับเบิลคลิก (หรือคลิกขวา → Extract All / แตกไฟล์) จะได้โฟลเดอร์ชื่อ `timeclock-app` — เก็บไว้ จะใช้ในขั้นที่ 3

## ขั้นที่ 1 — สมัคร/ล็อกอิน GitHub

1. เปิดเบราว์เซอร์ ไปที่ **github.com**
2. ยังไม่มีบัญชี → กด **Sign up** สมัครตามขั้นตอน (ถ้าเคยสมัครไว้จากตอนทำเว็บบันทึกออเดอร์แล้ว ใช้บัญชีเดิมได้เลย)

## ขั้นที่ 2 — สร้าง repository ใหม่ (แยกจากตัวบันทึกออเดอร์)

1. มุมขวาบนของหน้า github.com กดไอคอน **+** → **New repository**
2. ตั้งชื่อ เช่น `timeclock` (ใช้ชื่อแยกจาก repo เดิม เพราะเป็นคนละเว็บกัน)
3. เลือก **Private**
4. ไม่ต้องติ๊กอะไรเพิ่ม ปล่อย repo ว่างเปล่าไว้
5. กดปุ่มสีเขียว **Create repository**

## ขั้นที่ 3 — อัปโหลดไฟล์ทั้งหมดขึ้น GitHub

1. หลังสร้าง repo เสร็จ กดลิงก์ **uploading an existing file** (หรือ **Add file** → **Upload files**)
2. เปิดโฟลเดอร์ `timeclock-app` ที่แตกไว้ในขั้นที่ 0 เลือกไฟล์/โฟลเดอร์ **ทั้งหมด** ข้างใน (Ctrl+A หรือ Cmd+A)
3. ลากไปวางบนหน้าเว็บ GitHub รอจนอัปโหลดครบ
4. เลื่อนลงล่างสุด กด **Commit changes**

## ขั้นที่ 4 — Import เข้า Vercel

1. ไปที่ **vercel.com** ล็อกอิน (ใช้บัญชีเดิมที่เชื่อมกับ GitHub ได้เลยถ้ามีอยู่แล้ว)
2. กด **Add New...** → **Project**
3. หา repo `timeclock` กด **Import**
4. ปล่อยทุกอย่างเป็นค่าเริ่มต้น กด **Deploy** รอ 1-2 นาที

ตอนนี้เว็บขึ้นแล้วแต่ยังใช้งานจริงไม่ได้ ต้องเพิ่มฐานข้อมูลและตั้งรหัส PIN ก่อน — ทำขั้นที่ 5-6 ต่อ

## ขั้นที่ 5 — เพิ่มฐานข้อมูล (Upstash Redis)

1. ในหน้าโปรเจกต์ Vercel ไปแท็บ **Storage**
2. กด **Create Database** (หรือ **Browse Marketplace**) เลือก **Upstash** (Redis / KV) แพ็กเกจฟรี
3. ตั้งชื่อ กด Create/Continue แล้วเลือกเชื่อมกับโปรเจกต์ `timeclock` กด **Connect**

## ขั้นที่ 6 — ตั้งรหัส PIN สำหรับแอดมิน

ขั้นนี้ไม่เหมือนตัวบันทึกออเดอร์ เพราะเว็บนี้ต้องมีรหัสกันไม่ให้ลูกจ้างเข้าหน้าแอดมินได้:

1. ในหน้าโปรเจกต์ Vercel ไปแท็บ **Settings** → **Environment Variables**
2. ช่อง Key ใส่ `ADMIN_PIN`
3. ช่อง Value ใส่รหัสที่ต้องการ (ตัวเลขกี่หลักก็ได้ เช่น `1988`) — จำไว้ให้ดี อันนี้คือรหัสเข้าหน้าแอดมินของจริง
4. กด **Save**

## ขั้นที่ 7 — Deploy ซ้ำอีกครั้ง

ค่าที่เพิ่งตั้งในขั้นที่ 5-6 จะยังไม่มีผลกับเว็บที่ deploy ไปแล้ว ต้อง deploy ใหม่:

1. ไปแท็บ **Deployments**
2. deployment ล่าสุด กดจุดสามจุด **⋯** → **Redeploy** → ยืนยันอีกครั้ง

## ขั้นที่ 8 — ทดสอบ

1. เปิดลิงก์เว็บ เพิ่มชื่อพนักงานจริงในหน้าแอดมิน (กด "แอดมิน" มุมล่าง ใส่ PIN ที่ตั้งไว้)
2. กลับหน้าแรก ลองเลือกชื่อ กดเข้างาน แล้ว refresh ดู — ถ้าสถานะยังอยู่ แปลว่าใช้งานได้จริงแล้ว
3. ลองเข้าหน้าแอดมินด้วย PIN ที่ตั้งไว้ ดูว่าเห็นข้อมูลครบ

---

## ถ้าติดปัญหา

- ขั้นตอน GitHub / Vercel ทั่วไป (สร้าง repo, อัปโหลดไฟล์, import) เหมือนกับตอนทำเว็บบันทึกออเดอร์ทุกอย่าง ถ้าจำได้อยู่แล้วข้ามอ่านซ้ำได้
- เข้าหน้าแอดมินไม่ได้ทั้งที่ใส่ PIN ถูก → เช็คว่า deploy ซ้ำ (ขั้นที่ 7) หลังตั้งค่า ADMIN_PIN แล้วหรือยัง ถ้ายัง redeploy ค่าจะยังไม่มีผล
- ติดตรงไหนอื่น ส่ง error message หรือบอกว่าเห็นอะไรอยู่มาได้เลย
